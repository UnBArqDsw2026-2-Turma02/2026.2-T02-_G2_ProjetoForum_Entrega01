## Sobre

Este projeto tem como objetivo aplicar conceitos de Arquitetura e Desenho de
Software por meio de uma engenharia reversa de documentação, a partir do
fórum utilizado, [Stack Overflow](https://stackoverflow.com/). A partir da
observação desse tipo de plataforma, o grupo busca identificar público-alvo,
principais funcionalidades e fluxos de uso, para então reconstruir artefatos
de desenho de software (modelagens, diagramas e demais documentos) que
representem o funcionamento do sistema estudado.
