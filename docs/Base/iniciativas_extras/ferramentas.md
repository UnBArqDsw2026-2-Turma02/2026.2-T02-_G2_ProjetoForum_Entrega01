# 1.3.3. Ferramentas

Lista das ferramentas utilizadas pelo grupo ao longo da entrega (comunicação,
modelagem, gestão de tarefas, documentação, entre outras).

| Ferramenta | Finalidade |
| -- | -- |
| [GitHub](https://github.com) | Versionamento do repositório, branches, commits e revisão via Pull Requests. |
| [GitHub Issues](https://github.com/UnBArqDsw2026-2-Turma02/2026.2-T02-_G2_ProjetoForum_Entrega01/issues) | Gestão de tarefas em quadro Kanban (a fazer, em desenvolvimento, aguardando revisão, pronto). |
| [GitHub Pages](https://unbarqdsw2026-2-turma02.github.io/2026.2-T02-_G2_ProjetoForum_Entrega01/) | Publicação do site de documentação. |
| [Docsify](https://docsify.js.org/) | Geração do site estático de documentação a partir dos arquivos Markdown. |
| [Miro](https://miro.com) | Modelagem colaborativa do Rich Picture, do diagrama SIG do NFR Framework e do BPMN de monetização. |
| [Google Meet](https://meet.google.com) | Reuniões síncronas do grupo e dos subgrupos, com gravação. |
| [YouTube](https://www.youtube.com) | Hospedagem das gravações das reuniões, incorporadas nas atas. |
| [WhatsApp](https://www.whatsapp.com) | Comunicação rápida e informal entre o grupo geral e os subgrupos. |
| [Google Drive](https://drive.google.com) | Armazenamento e compartilhamento de arquivos complementares do grupo. |

## Conteúdo

A escolha das ferramentas seguiu a familiaridade da maioria dos integrantes
e a necessidade de manter todo o processo rastreável: GitHub e GitHub Pages
concentram o versionamento e a publicação da documentação, o Miro
centraliza a modelagem colaborativa (Rich Picture, NFR e BPMN), e Google
Meet, YouTube e WhatsApp cobrem a comunicação síncrona e assíncrona entre
os subgrupos.
