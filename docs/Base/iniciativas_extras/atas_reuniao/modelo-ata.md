# 1.3.4.2. Modelo de Ata

Modelo a ser duplicado para o registro de cada reunião realizada pelo grupo.
Ao criar uma nova ata, nomeie o arquivo como `ata-reuniao-XX.md` (XX = número
sequencial da reunião), adicione-o ao [_sidebar.md](../../_sidebar.md) e
inclua uma linha correspondente na
[Tabela de Rastreabilidade](./rastreabilidade.md).
