# 1.3.4.1. Rastreabilidade das Reuniões

## Organização das reuniões

As reuniões do grupo acontecem por meio do WhatsApp, em um grupo geral e em
grupos específicos para cada subequipe. Cada subgrupo possui uma liderança
própria, responsável por organizar as conversas e repassar os
encaminhamentos ao grupo geral. A coordenação geral do projeto (liderança
master) é exercida por **Caio Soares de Andrade**.

| Papel | Responsável |

| Liderança Master (coordenação geral) | Caio Soares de Andrade |

| Liderança - Subequipe_03 | _A definir_ |

As reuniões são registradas em dois grupos, seguindo a mesma divisão usada
na navegação desta seção: **Reuniões Gerais** (com a equipe toda) e
**Reuniões por Subequipe** (internas de cada subgrupo). Cada linha das
tabelas abaixo aponta para a ata detalhada correspondente (ver também o
[Modelo de Ata](./modelo-ata.md)).
