# 1.3.2. Mapa de Calor de Disponibilidade

Representação visual da disponibilidade de horários de cada integrante do
grupo, utilizada para facilitar a definição de horários de reunião.

## Conteúdo

A definição do horário fixo de reunião foi feita por meio de duas enquetes
no grupo geral do WhatsApp: primeiro o dia da semana, depois o horário
dentro do dia escolhido. Os mapas abaixo representam a intensidade de
votos recebida por cada horário (mais votos = cor mais quente).
